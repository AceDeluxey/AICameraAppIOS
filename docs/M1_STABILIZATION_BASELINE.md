# M1.5 防抖能力基线

> 记录日期：2026-08-31

## 用户模式与内部模式

- 首版用户入口只暴露“关闭”和“自动”。
- `standard`、`cinematic`、`cinematicExtended` 只作为开发诊断模式，不承诺所有镜头或格式可用。
- 每次镜头或格式变化后，必须重新读取当前 `activeFormat` 支持的模式并重新应用选择。
- 请求模式不受支持时按“自动 → 标准 → 关闭”降级；用户明确选择关闭时不得自动启用其他模式。

## 状态真实性

防抖状态同时记录三层信息：

1. 用户请求的模式。
2. 写入 `AVCaptureConnection.preferredVideoStabilizationMode` 的模式。
3. 系统返回的 `activeVideoStabilizationMode`。

UI 最终应以实际生效模式为准。请求模式与生效模式不一致时保留降级标记，不显示虚假的“已开启”。

## 尚待真机完成

- 固定镜头、倍率、格式和帧率录制关闭/自动/内部模式对照样本。
- 分别评估预览位移与延迟、照片清晰成片率、视频抖动与裁切。
- 记录长焦、走动、跟拍和外接望远镜场景的功耗、温度及果冻效应。
- 组织盲测后决定系统防抖是否足够；未证明收益前不进入 Core Motion 自定义方案。
