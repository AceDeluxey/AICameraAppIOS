# M2 拍照 MVP 实现说明

> 代码状态：主链路已实现并通过模拟器构建；相机行为、出片和性能结论仍以真机验收为准。

## 已实现

- 相机会话按会话、拍照与镜头、鸟体检测、生命周期拆分，所有硬件操作在独立队列执行。
- 固定使用实际物理后置镜头，按设备能力生成镜头按钮；支持滑杆和双指缩放，切镜头后重读能力与防抖状态。
- 支持 4:3、16:9 所见即所得取景和整数像素中心裁切，拍照后按需写入拍摄时间与位置并保存到系统照片。
- 提供最近成片缩略图、系统照片选择器、点按对焦、人工对焦反馈及 44pt 以上触控区域。
- 实现黑色取景背景、橙色强调色、五类构图线、鸟模式持久化、检测框和模型缺失降级。
- Core ML 优先、TFLite 备选的运行时工厂已接入真实视频帧；模型缺失或推理失败不影响拍照。
- 相机中断、媒体服务重置、前后台、内存警告和温度升高均有恢复或降频处理。

## 仍需外部条件

- 仓库暂不包含来源与复用授权未确认的检测模型，鸟模式会明确显示模型不可用，但相机仍可拍照。
- 镜头切换、照片方向、照片权限、位置元数据、检测框对齐、对焦、防抖和持续运行必须在实体 iPhone 验收。
- Android 视觉逐项对照、两台不同能力 iPhone 回归和 20 分钟性能记录尚未执行。
