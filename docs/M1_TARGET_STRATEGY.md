# M1.3 整鸟对焦目标策略

> 记录日期：2026-08-31

## 首版规则

- 每帧只选择置信度最高的整鸟检测框，不把结果解释为鸟头或鸟眼。
- 强置信度阈值暂定 `0.65`，达到后立即确认目标。
- 弱置信度阈值暂定 `0.30`，同一目标需连续命中 3 帧才确认；低于该阈值时回到搜索状态。
- 连续帧使用 IoU 判断是否为同一目标，暂定最低 IoU 为 `0.20`；不匹配时重新开始确认。
- 已确认框采用指数平滑，当前帧权重暂定 `0.35`，避免覆盖层和对焦点随检测框抖动。
- 整鸟对焦点取平滑后矩形的几何中心，并限制在标准化图像坐标 `0...1` 内。
- 已确认目标发生不重叠的强置信切换时，禁止跨目标平滑，直接建立新目标。

以上阈值均是可测试的初始配置，不是最终产品参数。待固定验证集与真机样本具备后，根据误触发、确认延迟和目标保持率调整。

## 状态语义

| 状态 | 含义 | 可否触发 AI 对焦 |
| --- | --- | --- |
| `searching` | 没有达到最低置信度的目标 | 否 |
| `confirming` | 弱置信目标正在累计连续帧 | 否 |
| `confirmed` | 强置信立即确认，或弱置信已满足连续帧要求 | 是 |

短暂漏检恢复、相机坐标映射、对焦重触发间隔和人工点按优先属于 M1.4，不在本阶段假定已经完成。

## 待采集失败样本

- 背身或只露出局部身体
- 树枝、树叶或网格遮挡
- 远距离小目标
- 飞行或运动模糊
- 多鸟交叠、接近或置信度交替

样本必须保留原始图像、检测框、置信度和预期主目标；未确认授权的用户媒体不得提交到 Git。
