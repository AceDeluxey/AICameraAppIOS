# M3.2 地理先验

鸟种分类支持可选的 GPS 分省分月先验，并保持与 Android `BirdRegionPrior` 相同的数据格式和权重：

- 当月或相邻月有记录：`1 + 6 × level / 255`，相邻月按 `0.5` 衰减。
- 省内年度有记录但当前季节无记录：`0.22`。
- 全国有记录但该省无记录：`0.15`。
- 全国无记录：`0.05`。
- 无权限、无定位、境外或省界不匹配：`1.0`，即纯模型结果。

“照片记录位置”和“位置优化鸟种候选”是两个独立开关。后者默认关闭，仅在用户主动开启且鸟类模式运行时请求定位；关闭后立即清除内存中的位置先验。

运行时会可选加载 `bird_region_prior.txt` 和 `china_provinces_poly.txt`。资源缺失或损坏时自动退化为纯模型分类，不影响相机、检测和保存。两份 Android 资产需确认复用授权后才能加入 `Resources`，加入前保持本地和安装包中均不包含这些数据。
