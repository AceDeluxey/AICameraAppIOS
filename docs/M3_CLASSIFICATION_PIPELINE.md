# M3 鸟种分类链路

## 模型契约

- Core ML 资源名：`BirdClassifier.mlmodelc`
- 标签资源名：`bird_labels_dongniao.txt`
- 输入：`input`，float32 `[1, 3, 224, 224]`
- 通道：RGB、NCHW、ImageNet mean `[0.485, 0.456, 0.406]`、std `[0.229, 0.224, 0.225]`
- 输出：`output`，末维为 10,964 个 logits
- 标签：每行 `中文名|English|Scientific`，行号与模型输出索引一致

分类裁切以已确认整鸟框为中心，按最大边扩展为 1.25 倍正方形并限制在原始帧内。后处理使用数值稳定 softmax，最多输出 Top 3。

## 实时调度与显示

- 只有鸟体跟踪状态为 `confirmed` 时才提交分类。
- 分类最短间隔为 1 秒；上一任务未完成时丢弃新请求，不阻塞预览、检测、对焦或快门。
- 首个结果立即显示；Top 1 变化需连续两次一致才切换，避免候选名称单帧闪烁。
- 顶部最多显示三行中文名称与概率；录制暂停 AI、目标丢失或鸟模式关闭时清除候选。
- 模型或标签缺失时分类静默降级，鸟体检测和拍摄链路继续工作；运行时推理错误仅更新分类状态。

## 资产与验收

模型和标签当前不提交仓库。获得明确复用授权后，应固化来源、版本、SHA-256 和转换工具版本，再加入资源构建配置。随后使用同一验证集比较 Android/iOS Top-1、Top-3 与数值偏差，并在真机记录延迟、内存、发热和功耗。
