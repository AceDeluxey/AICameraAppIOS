# M1.4 主目标保持与 AI 对焦策略

> 记录日期：2026-08-31

## 默认参数

| 参数 | 初始值 | 目的 |
| --- | --- | --- |
| 漏检容忍 | 2 帧 | 避免枝叶遮挡或单帧检测失败导致目标立即消失 |
| 最短重对焦间隔 | 0.75 秒 | 避免频繁下发对焦造成抽焦 |
| 最小目标位移 | 标准化坐标 0.08 | 稳定目标不重复触发对焦 |
| 人工对焦保护 | 2 秒 | 用户点按后 AI 暂不抢焦 |

这些值是可配置的测试基线，必须结合固定样本和真机结果修订。

## 决策顺序

1. 只有 `confirmed` 主目标可以触发 AI 对焦。
2. `confirming` 与 `temporarilyLost` 不下发新对焦，后者暂时保留最后一次框。
3. 用户点按对焦后进入保护窗口；窗口内禁止 AI 对焦和自动回退覆盖用户选择。
4. 保护窗口外，目标移动达到阈值且满足最短间隔时才重新对焦。
5. 漏检超过容忍帧数后，目标进入 `searching`，相机只回退一次系统连续自动对焦。

## 坐标链路

模型输出使用旋转转正后的图像标准化坐标，原点为左上角。映射时依次执行：

1. 用转正后的实际图像尺寸恢复图像点。
2. 按预览层的 `resizeAspectFill`、`resizeAspect` 或 `resize` 规则计算裁切和缩放。
3. 得到预览层坐标后，通过 `AVCaptureVideoPreviewLayer.captureDevicePointConverted` 转为相机对焦坐标。
4. 下发前把设备坐标限制在 `0...1`。

图像方向、镜像状态和转正尺寸必须来自当前帧与预览连接，禁止按机型硬编码。

## 尚待真机验证

- 自动对焦与连续自动对焦模式在各物理镜头上是否真实生效。
- 4:3、16:9、横竖屏和前后摄像头组合的坐标叠加误差。
- 静止鸟、移动鸟、遮挡和多鸟场景的抽焦次数与目标保持率。
- 检测、对焦下发、对焦完成和目标丢失时间点的端到端诊断记录。
